# Python Day 82 - Sum of Even and Odd Numbers

This program calculates the separate sum of even and odd numbers from a Python list.

## Example

Input:
[10, 15, 22, 33, 40, 57, 68, 71]

Output:
Sum of Even Numbers: 140
Sum of Odd Numbers: 176

## Concepts Used

- Lists
- for loop
- if-else
- Modulus Operator (%)
- Variables
- Even and Odd Numbers
- Sum Calculation
